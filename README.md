## Deployment

This repository includes a GitHub Actions workflow (`.github/workflows/deploy.yml`) that deploys the repository root directly to GitHub Pages on every push to `main` — no build step required.

**Setup Instructions:**

1. Go to your repository Settings > Pages
2. Under "Build and deployment", select:
   - Source: **GitHub Actions**
3. Push your changes to the `main` branch
4. Your site will be available at `https://ribeirohugo.github.io`
